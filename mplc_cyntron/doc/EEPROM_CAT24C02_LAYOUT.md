# Разметка внешней EEPROM (CAT24C02, 2 Kbit = 256 байт)

При загрузке в отладочный вывод один раз выводится строка:
`[EEPROM] external: total=256 B, used=<N> B, free=<M> B`

Ниже — какие параметры сохраняются в конфигурации и сколько байт они занимают.

## Структура конфигурации `tConfig` (одна запись в EEPROM)

| Параметр | Тип | Размер (байт) | Описание |
|----------|-----|---------------|----------|
| `index` | uint8_t | 1 | Индекс устройства |
| `baudrate` | uint16_t | 2 | Скорость RS-485 (12=1200 … 1152=115200) |
| `parity` | uint8_t | 1 | Чётность (0=none, 1=odd, 2=even) |
| `stopbits` | uint8_t | 1 | Стоп-биты (1 или 2) |
| `modbusaddress` | uint8_t | 1 | Modbus-адрес |
| `otladka` | struct debug_bits | 4 | Биты отладки (32 флага) |
| `watchdog_number` | uint8_t | 1 | Счётчик срабатываний watchdog |
| `reset_inactivity` | uint8_t | 1 | Таймаут неактивности (сброс DO/AO), ×100 мс |
| `ai_settings[16]` | ai_settings_t[16] | 80 | Настройки AI: тип датчика (0..24), верхний/нижний предел (по 2 байта × 16 каналов) |
| `ai_calibration_offset[12]` | int16_t[12] | 24 | Калибровка AI: смещение ×0.1 °C (−100…+100), 12 каналов |
| `ai_kalman_value_enable` | uint8_t | 1 | Включение фильтра Калмана по умолчанию (1/0) |
| `running_line` | uint8_t | 1 | Сдвиг «бегущей строки», единица = 10 мс |
| `crc` | uint16_t | 2 | CRC конфигурации |

**Сумма полей (без учёта выравнивания):** 1+2+1+1+1+4+1+1+80+24+1+1+2 = **119 байт**.  
Фактический размер задаётся `sizeof(tConfig)` (может быть больше из-за выравнивания структуры).

## Использование памяти CAT24C02 (256 байт)

- **Всего:** 256 байт (2 Kbit).
- **Занято под конфигурацию:** `sizeof(tConfig)` байт (константа `EEPROM_CONFIG_USED_BYTES` в `i2c.c`).
- **Свободно:** `256 - sizeof(tConfig)` байт (константа `EEPROM_FREE_BYTES` в `i2c.c`).

Счётчики DO/DI в EEPROM для CAT24C02 **не хранятся** (нет места); резервная копия сетевых настроек в конце EEPROM для 2 Kbit **не используется**.

- **Байты 252..255:** серийный номер устройства (4 байта, LE). Дублирует значение во Flash по адресу 0x080000C4. При первой прошивке серийный задаётся прошивальщиком (рег. 1005) и пишется во Flash и в EEPROM. При старте основного приложения серийный из Flash сохраняется в EEPROM (если ещё не совпадает), чтобы при слете прошивки бутлоадер мог восстановить его из EEPROM во Flash. Бутлоадер при чтении рег. 270–271 и при выборе по серийному (0xF0) считает серийный корректным только если он в диапазоне 0x0E0A0000..0x0E0AFFFF (не 0, не 0xFFFFFFFF); при пустом Flash и корректном серийном в EEPROM бутлоадер при старте восстанавливает серийный из EEPROM во Flash.

Функции для отчёта в отладке: `eeprom_get_total_bytes()`, `eeprom_get_config_used_bytes()`, `eeprom_get_free_bytes()` — объявлены в `ee24.h`, реализация в `i2c.c`.
