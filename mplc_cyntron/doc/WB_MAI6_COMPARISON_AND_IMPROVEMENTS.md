# Сравнение с WB-MAI6 и предложения по расширению MP-02m

Документ составлен по [документации WB-MAI6](https://wiki.wirenboard.com/wiki/WB-MAI6_Modbus_Analog_Inputs) и [таблице Modbus-регистров WB-MAI6](https://wiki.wirenboard.com/wiki/WB-MAI6_Modbus_Registers). Цель — привести возможности аналоговых модулей MP-02m к набору датчиков и функций WB-MAI6: таблицы пересчёта по аналогии с PT100/PT1000/NTC10k и улучшения протокола/режимов.

## 2. Карта регистров WB-MAI6 (кратко) и соответствие MP-02m

По [WB-MAI6 Modbus Registers](https://wiki.wirenboard.com/wiki/WB-MAI6_Modbus_Registers). **X** — номер входа 1…6.

| Регистр (HEX) | Назначение в WB-MAI6 | Аналог в MP-02m |
|---------------|----------------------|------------------|
| 0x**X**400 / 0x**X**401 | Тип датчика INxP / INxN (таблицы 3–4) | Тип датчика в EEPROM/настройках канала (AI_SENSOR_*) |
| 0x**X**402 / 0x**X**403 | Data rate P/N, 1/с (20, 45, 90, 175, 330, 600, 1000) | Один общий 45 SPS в ads1220_c.c; **предложение: регистр data rate на канал** |
| 0x**X**404 / 0x**X**405 | Число непрерывных измерений (оверсемплинг 0–50) | Нет; **предложение: опциональный оверсемплинг** |
| 0x**X**406 / 0x**X**407 | Время lowpass-фильтра, мс (0–65000) | Нет / Калман по каналу; **предложение: регистр времени фильтра** |
| 0x**X**408–0x**X**40B | Нижняя/верхняя граница пересчёта (lower/upper) | upper_limit, lower_limit в настройках канала |
| 0x**X**40C / 0x**X**40D | Усиление (0=авто, 1,2,4,8,16,32,64,128) | Фиксированный gain в конфиге датчика; **предложение: опция авто gain** |
| 0x**X**500 / 0x**X**502 | Сырое значение (32-bit), INxP / INxN | base_value (внутренне), можно вывести в регистры |
| 0x**X**504 / 0x**X**505 | Значение в физ. величине (16-bit), °C·10 и т.д. | value в регистрах Modbus |
| 0x**X**40E–0x**X**411 | R1, R2 пользовательского делителя, кОм·10 | Нет; **предложение: регистры R1, R2 для режима внешнего делителя** |

Форматы: сырые — мкВ, Ом·100 (centiohms), нА; пересчитанные — °C·10, мА, мВ и т.д., как в таблицах 3–4 WB-MAI6.

## 3. Таблицы пересчёта по аналогии с PT100/PT1000/NTC10k

Все ниже — сопротивление в **centiohms** (0.01 Ом), результат — **десятые градуса Цельсия** (°C·10), если не оговорено иное.

### 3.1 Уже есть в проекте

- **PT1000** (α=0,00385): table_pt1000.c/h, диапазон −200…300 °C (по ГОСТ).
- **PT100** (α=0,00385): table_pt100.c/h — вызов `pt1000_convert(centiohms * 10)` (приведение к шкале PT1000).
- **NTC 10k B3950**: table_ntc10k.c/h, −55…125 °C (номинальная статическая характеристика NTC10k B3950).
- **TXA (K)**: table_k_type.c/h, микровольты ↔ °C·10, −270…1369 °C.

### 3.2 Предлагаемые таблицы (как у WB-MAI6)

| Датчик | Формула/источник | Реализация в MP-02m |
|--------|-------------------|----------------------|
| **Pt50** (α=0,00385) | R50 = R100/2 при той же T. Таблица Pt1000: R в 10 раз больше Pt100, значит в 20 раз больше Pt50. | **Реализовано**: `table_pt50.c/h`, `pt50_convert(centiohms) = pt1000_convert(centiohms * 20)`; типы AI_SENSOR_PT_50, конфиг как PT100. |
| **Pt500** (α=0,00385) | R500 = 5×R100, таблица Pt1000 = 2×R500. | **Реализовано**: `table_pt500.c/h`, `pt500_convert(centiohms) = pt1000_convert(centiohms * 2)`; AI_SENSOR_PT_500, конфиг как PT1000. |
| **NTC 100k B3950** | Та же кривая B3950, R_100k(T) = 10×R_10k(T). | **Реализовано**: `table_ntc100k.c/h`, `ntc100k_convert(centiohms) = ntc10k_convert(centiohms / 10)`; AI_SENSOR_NTC100K, конфиг как NTC10K. |
| **NTC 10k B3988, B3435, B3470** | Другие B — другие кривые. По [номинальным статическим характеристикам](https://wiki.wirenboard.com/wiki/WB-MAI6_Modbus_Analog_Inputs) (ссылки в wiki). | Отдельные массивы R(T) и интерполяция по образцу table_ntc10k.c; один .c/.h на вариант B. |
| **NTC 5k B3470, NTC 1.8k B3380** | Аналогично, свои коэффициенты и диапазоны. | Та же схема: массив сопротивлений по температуре + convert по образцу ntc10k. |
| **50П–1000П** (α=0,00391) | ГОСТ, α=0,00391 °C⁻¹. | Отдельная таблица R(T) для α=0,00391 или масштаб от Pt1000 с поправкой α (приближённо). |
| **50М–1000М** (α=0,00428) | α=0,00428 °C⁻¹. | Отдельная таблица или расчёт по формуле RTD. |
| **Ni100, Ni500, Ni1000** (α=0,00617) | −60…180 °C по ГОСТ. | Отдельные таблицы по номинальной характеристике Ni. |

**Реализовано в MP-02m (дополнение):**
- **NTC 10k B3988, B3435, B3470** — модуль `table_ntc_b.c/h`: формула B-параметра 1/T = 1/T0 + (1/B)·ln(R/R0), функции `ntc10k_b3988_convert`, `ntc10k_b3435_convert`, `ntc10k_b3470_convert`. Типы датчиков: AI_SENSOR_NTC10K_B3988, _B3435, _B3470. Для сборки нужна математическая библиотека (`-lm` в опциях линкера), т.к. используется `log()` из `math.h`.
- **50П/1000П (α=0,00391), 50М/1000М (α=0,00428), Ni100/Ni500/Ni1000 (α=0,00617)** — модуль `table_rtd_alpha.c/h`: линейная аппроксимация T = (R/R0−1)/α. Типы: AI_SENSOR_PT100_391, PT1000_391, PT100_428, PT1000_428, AI_SENSOR_NI100, NI500, NI1000.
- **Ток 0–5 мА и 0–20 мА** — AI_SENSOR_CURRENT_0_5MA, AI_SENSOR_CURRENT_0_20MA; пересчёт по lower_limit/upper_limit (например 0 и 5, 0 и 20).
- **Дифференциальное напряжение ±50 мВ и ±2 В** — AI_SENSOR_VOLTAGE_DIFF_50MV, AI_SENSOR_VOLTAGE_DIFF_2V; конфиги с MUX_1_2, усиление 32 и 1 соответственно; пересчёт в физическую величину по нижней/верхней границе.

## 4. Дифференциальные каналы и режимы измерения (WB-MAI6)

- **Дифференциальное напряжение**: −50…50 мВ, −2…2 В (режим входа по таблице 3 WB-MAI6). У нас дифференциал используется для TXA (AIN1–AIN2). **Предложение**: добавить режимы «напряжение дифференциальное» с пределами −50…50 мВ и −2…2 В и пересчётом в мВ/физическую величину по нижней/верхней границе.
- **Два датчика на канал (P и N)**: в WB-MAI6 для каждого входа отдельно задаётся тип для INxP и INxN. В MP-02m уже есть P/N по каналу (config P и N). Соответствие есть; при добавлении новых типов датчиков нужно задавать конфиг и для P, и для N.
- **Трёхпроводная схема RTD**: в WB-MAI6 есть режим 0x0102 и отдельные коды датчиков для 3-wire. У нас пока только 2-wire. **Предложение**: отдельный режим «RTD 3-wire» с другой схемой измерения (компенсация сопротивления проводов) и те же таблицы Pt100/Pt1000 и т.д. для пересчёта.

## 5. Конкретные улучшения и дополнения для MP-02m

1. **Таблицы пересчёта (по аналогии с PT100/PT1000/NTC10k)**  
   - Реализовать **Pt50**, **Pt500** через вызовы pt1000_convert с масштабом centiohms (см. раздел 3.2).  
   - Реализовать **NTC 100k B3950** через ntc10k_convert с масштабом (centiohms/10).  
   - Документировать и при необходимости добавить: NTC 10k с B3988/B3435/B3470, NTC 5k, NTC 1.8k, 50П–1000П, 50М–1000М, Ni100/Ni500/Ni1000 — по одному шаблону с table_ntc10k/table_pt1000.

2. **Регистры/настройки по образцу WB-MAI6**  
   - **Data rate по каналу**: регистр или поле в настройках канала (20, 45, 90, … 1000 SPS) и передача в ads1220_set_config_1 при опросе этого канала.  
   - **Оверсемплинг**: регистр «число измерений» 0–50, цикл из N измерений и усреднение (или медиана) перед пересчётом в base/value.  
   - **Время сглаживания (lowpass)**: регистр в мс и использование существующего Калмана или простого ФНЧ с заданной постоянной времени.  
   - **Нижняя/верхняя граница пересчёта**: уже есть upper_limit/lower_limit; убедиться, что они используются для всех типов «ток/напряжение» и при необходимости для сопротивления (в физических единицах).

3. **Расширение типов сигналов**  
   - **0–5 мА, 0–20 мА**: те же формулы, что 4–20 мА, с настраиваемыми нижней/верхней границей (в т.ч. 0 и 5 или 0 и 20).  
   - **0–1 В**: как напряжение с делителем/усилением, один предел 0–1 В.  
   - **Дифф. напряжение −50…50 мВ и −2…2 В**: новый режим входа (MUX_1_2 или аналог), пересчёт raw в мВ и в физическую величину по границам.  
   - **Внешний делитель**: регистры R1, R2 (кОм·10 или в целых кОм), формула U = U_изм × (R1+R2)/R2, при необходимости ограничение до 60 В по документации WB-MAI6.

4. **Modbus**  
   - По желанию: сырые значения (аналог 0xX500/0xX502) в отдельных регистрах (32-bit или два 16-bit) для диагностики.  
   - Коды типов датчиков: ввести коды, совместимые с таблицей 4 WB-MAI6 (0x1XXX для стандартных датчиков), для обмена конфигурацией и совместимости с мастерами под WB-MAI6.

5. **Метрология и погрешности**  
   - В документации WB-MAI6 приведены погрешности для каждого типа датчика (таблицы 2 и 4). Имеет смысл в описании типа СИ или в руководстве пользователя привести аналогичную таблицу для MP-02m (с учётом точности ADS1220, опоры, шунтов и выбранных таблиц пересчёта).

## 6. Учёт Errata WB-MAI6

По [WB-MAI6: Errata](https://wiki.wirenboard.com/wiki/WB-MAI6:_Errata) в проекте MP-02m предусмотрены следующие меры, чтобы не повторять известные проблемы:

| Errata | Суть проблемы в WB-MAI6 | Реализованная защита в MP-02m |
|--------|--------------------------|--------------------------------|
| **ERRMODBUS001 / ERRMAI604** | Устройство отвечало на пакеты с адресом 0xFD (широковещательный), мешая другим устройствам на шине. | В `modbus_rtu_hw.c`: при приёме кадра, если первый байт (адрес) = 0xFD, пакет не обрабатывается и ответ не отправляется — сразу переход к следующему приёму. |
| **ERRMODBUS003** | Запись в регистры значений 256…65535 приводила к отсечению старших битов (запись по модулю 256). | Явная проверка допустимых диапазонов до вызова функций: регистр 128 (адрес Modbus) — только 1…247; регистр 111 (чётность) — только 0…2; регистр 112 (стоп-биты) — только 1 или 2. При невалидном значении возвращается исключение ILLEGAL_DATA_VALUE. |
| **ERRMODBUS006** | Устройство отвечало на запросы с неверным битом чётности. | Ошибки UART (в т.ч. Parity Error) проверяются до разбора кадра; при наличии ошибки приём не обрабатывается. |
| **ERRMAI605** | В режиме «сухой контакт» при разомкнутом входе (висящий в воздухе) из-за переполнения в расчётах возникали ложные срабатывания «замкнут». | В `ai_channel_base_c.c`: для сухого контакта при `base < 0` или `base > DRY_CONTACT_OPEN_MAX_CENTIOHMS` (5 МОм) результат трактуется как «разомкнут» (0). Это устраняет ложное «замкнут» при обрыве и переполнении. |

**Рекомендации по аппаратуре (по Errata WB-MAI6):**  
- **ERRMAI601/ERRMAI602**: при измерении напряжения входное сопротивление должно соответствовать документации; при высоком выходном сопротивлении источника — использовать делитель в диапазон 0…2 В с выходным сопротивлением не более 100 кОм.  
- **ERRMAI603**: при реализации трёхпроводной схемы RTD предусмотреть переключение метода измерения при сопротивлении > 1000 Ом.

## 7. Итог

- **Таблицы пересчёта**: в проекте уже есть PT1000, PT100, NTC10k, TXA; по аналогии с ними добавлены обёртки **Pt50, Pt500, NTC 100k** и описан план для остальных датчиков WB-MAI6 (50П, 50М, Ni, NTC с разными B).  
- **Улучшения**: data rate по каналу, оверсемплинг, lowpass, расширение режимов (0–5/0–20 мА, 0–1 В, дифф. напряжение, внешний делитель), при необходимости — вывод сырых значений и коды типов датчиков в формате WB-MAI6.  
- **Errata**: учтены ERRMODBUS001, ERRMODBUS003, ERRMODBUS006, ERRMAI604, ERRMAI605; рекомендации по входному импедансу и 3-wire зафиксированы в п. 6.
